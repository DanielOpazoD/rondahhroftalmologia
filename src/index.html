1 · PDF de atenciones

    
Un PDF por atención sobre la hoja oficial, nombrado Oftalmo_fecha_RUT_nombre.pdf, listo para subir a la ficha de cada paciente. Si algo no cabe en la hoja, se agrega una hoja complementaria.

    

      
      
    

  


  

    
2 · Estadística (Excel)

    
Libro .xlsx con hojas: Resumen (indicadores, procedimientos por ojo, diagnósticos, solicitados, gestiones, sexo, operativo y médico), Atenciones (una fila por atención), Prestaciones (una fila por procedimiento realizado), Por día y Edad y sexo.

    
  


  

    
3 · Datos seudonimizados (análisis / IA)

    
Sin nombre, RUT, teléfono ni médico. Cada paciente recibe un código estable (P-XXXXXXXX): el mismo paciente tiene el mismo código en todas sus atenciones y exportaciones de este equipo. Los textos libres se limpian de RUT, teléfonos, correos, fechas y nombres.

    

      

      

      

    

    

      
      
      
    

    

    

    

      Tabla de correspondencia (confidencial)
      
Relaciona cada código con el nombre y RUT. Sirve para volver a identificar a un paciente si el análisis lo requiere. Guárdala separada de los datos y no la subas a servicios externos.

Sincronización entre equipos Desactivada

    
Mantiene iguales los datos de varios PC a través del servidor (Netlify). Cada atención se cifra en este equipo con la contraseña del equipo antes de enviarse: el servidor no puede leer nombres, RUT ni datos clínicos. Sin internet se sigue trabajando y se sincroniza al volver la conexión.

    
La sincronización solo funciona al abrir la app desde su dirección web (https). Con el archivo abierto con doble clic, usa «Respaldo y unión de equipos».

    

      
      

        
        
        
      

      
Genérala en el primer PC y escríbela igual en los demás. Guárdala en un lugar seguro: si se pierde, los datos del servidor no se pueden descifrar (los de cada PC no se pierden).

      
    

    

      

      

        
        
      

      

        Configuración del servidor (una sola vez)
        
En Netlify → Site configuration → Environment variables, crea la variable SYNC_TOKEN_SHA256 con este valor y vuelve a publicar el sitio. Este valor no permite leer los datos.

        

        
      

    

  


  

    
Respaldo y unión de equipos

    
Los datos quedan solo en este dispositivo y navegador. Descarga un respaldo al terminar cada jornada. Para juntar la estadística de varios equipos, importa los respaldos en uno solo: se suman sin duplicar.
