# ADR 0011: Modo práctica con almacenamiento aislado

**Estado:** Aceptada

## Contexto

El personal usa la app una o dos veces al año y necesita practicar sin ensuciar los datos reales.

## Decisión

- `?practica` abre la misma app con otra base IndexedDB y las claves de `localStorage` con el prefijo `practica:`, y carga datos de ejemplo.
- Nunca se sincroniza. Las descargas llevan el prefijo `PRACTICA_` y los respaldos de práctica se rechazan fuera de ella.

## Consecuencias

- Es la misma app (nada que mantener aparte).
- Todo lo que guarde estado fuera del `store` debe respetar el modo, como la clave de sesión del perfil (corregido tras una revisión).

## Alternativas descartadas

- **Sitio de demostración separado:** se desactualizaría respecto de la app real.
