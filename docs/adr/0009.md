# ADR 0009: HTML seguro por construcción

**Estado:** Aceptada

## Contexto

La interfaz arma HTML con datos de pacientes. Escapar a mano en 26 lugares dependía de no olvidarse nunca.

## Decisión

- Toda la interfaz usa la plantilla `html\`…\``, que escapa cada valor interpolado, y escribe con `setHtml`, que solo acepta esas plantillas.
- ESLint prohíbe `innerHTML`, `outerHTML` e `insertAdjacentHTML` directos.
- La política de contenido (CSP) solo permite el script de la app, identificado por su hash.

## Consecuencias

- El escape es la opción por defecto: no hay que recordarlo.
- El marcado fijo del código va en plantillas sin datos. `raw()` existe, pero no se usa con datos.

## Alternativas descartadas

- **Framework con plantillas:** ver ADR 0001.
